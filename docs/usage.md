# 使用念匣

安装入口见[首页](../README.md)。本文中的 Settings、Tasks 等名称沿用 App 当前的界面文字。

## 记录与整理

默认将鼠标移到屏幕右上角打开面板。点击添加按钮，或按 `Control–Option–Space` 直接开始快速记录；写下标题后按 Return 保存。Settings 可更换触发角落、显隐延迟与透明效果。

| 操作 | 结果 |
| --- | --- |
| 在 Tasks 添加 | 记为待办 |
| 在 Backlog 添加 | 收起暂不安排的想法 |
| 选择优先级 | 设置 None／Low／Medium／High |
| 双击事项 | 切换待办与进行中 |
| 点击完成按钮 | 标记完成；保留在 Done 历史 |
| 打开事项菜单 | 修改标题、优先级、状态，复制或显式删除 |
| 同一分组内拖动 | 调整本机顺序；优先级与分组规则仍生效 |
| 面板搜索 | 按标题查找；关闭搜索恢复列表 |

Tasks 与 Backlog 分别保留未提交的标题和优先级。切换标签或暂时关闭输入框后，重新打开可以继续；成功保存或显式取消才清空对应草稿。草稿仅在本次进程会话中保留，退出 App 前请保存。

已保存的事项与待同步更改写入本地数据库，退出重开后仍在。完成历史保留到主动删除；服务端删除不能通过旧离线编辑复活。

## 快捷键

在 Settings 点击 Quick capture shortcut，按下需要的组合。Escape 取消录制，Delete 停用，Restore default shortcut 恢复 `Control–Option–Space`。快捷键冲突时保留原设置；保存的组合在重开 App 后继续生效。

## 看懂菜单栏状态

| 图形或动作 | 含义 |
| --- | --- |
| 抽屉中的纸张抬起 | 已打开录入，尚未保存 |
| 纸张落入抽屉 | 本地记录保存成功 |
| 小圆点／暂停符号 | 有更改等待同步／当前离线 |
| 转动弧线 | 正在传输有内容的同步工作；短于 600 ms 的工作不显示转动 |
| 短暂对勾 | 已完成本轮服务端同步，待处理与冲突队列均已清空 |
| 断开的插头 | 连接或服务端请求失败 |
| 抽屉上的大叉 | 本地保存失败；检查文字错误提示后重试 |
| 分开的两张纸 | 远端删除与本地编辑冲突；保留编辑供导出 |

“已存到本机”与“已同步”是两次独立确认。没有新内容的后台轮询保持静止；同步成功图形短暂出现后恢复普通状态。开启 macOS 系统设置 → 辅助功能 → 显示 → 减少动态效果，使用静态状态提示。

打开菜单或 Settings 查看文字原因与队列数量。保存失败时，当前输入不会因失败而清空。冲突时从 Settings 的 Export local data 导出保留的编辑，再决定是否以新事项恢复内容。

## 连接自己的服务器

本机记录不需要账户或服务器。需要跨设备使用时，先按[部署指南](deployment.md)准备独立服务，在 Settings 填写服务地址与令牌；Hermes 的配置见[接入指南](hermes.md)。Mac 使用服务的根地址，Hermes 使用同一地址下的 `/mcp/`。

已保存的离线更改会在恢复连接后重试。停用同步会保留本机更改；更换服务器属于数据迁移，应先导出对账。请保管令牌，避免在截图或反馈中提供它。

## 常见边界

- 截止时间可由 Hermes 设置，Mac 显示并用于查询；目前不会到点通知。
- Mac 关闭时，只有部署在独立常开设备上的服务端仍可供 Hermes 访问。
- 普通升级保留现有数据；旧 Peekaboo 存储不会自动导入。
- 备份、删除冲突与恢复流程见[部署与数据恢复](deployment.md)，已验证设备范围见[验证记录](verification.md)。
