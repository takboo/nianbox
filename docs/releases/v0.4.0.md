# 念匣 0.4.0

这次更新补齐快速复制、完整备注查看、Homebrew 安装和应用内更新提醒。

- 鼠标悬停事项后可一键复制标题与完整备注，保留换行、空行和缩进；成功后显示短暂反馈。右键和事项菜单提供复制内容、仅标题、Markdown 三种格式。
- 单击选中事项后可用上下键切换，按 `⌘C` 复制。搜索、录入和标题编辑框中的文字复制保持系统行为。
- 点击备注预览可展开完整内容，支持滚动、局部文字选择和复制。浮层打开时面板保持显示，关闭后恢复自动收起。
- 本仓库提供 Homebrew Cask，使用公开 Universal DMG 和固定 SHA-256。升级、卸载及相同 App 的接管保留本地记录与待同步更改。
- 菜单栏和 Settings 提供 Check for Updates…；可关闭的每日后台检查发现正式稳定版后，在面板、菜单和 Settings 显示入口。下载与安装仍由用户手动完成，Settings 可复制 Homebrew 升级命令。

## 安装与升级

支持 macOS 14+、Apple Silicon 与 Intel。下载 `NianBox-0.4.0-universal.dmg`，保存草稿并退出旧 App 后，将新版拖入 Applications。

Homebrew 安装：

```sh
brew tap takboo/nianbox https://github.com/takboo/nianbox
brew install --cask takboo/nianbox/nianbox
```

已由 Homebrew 管理的安装可在保存草稿并退出后执行：

```sh
brew update
brew upgrade --cask takboo/nianbox/nianbox
```

Cask 在正式 Release 公开并核对产物后更新；首次使用 tap 前请确认定义已经指向 0.4.0。DMG 安装的 App 只有与待安装产物完全一致时才能通过 `--adopt` 接管，详见[安装指南](https://github.com/takboo/nianbox/blob/v0.4.0/docs/installation.md)。

更新检查只读取公开 GitHub Release 信息，不读取服务器令牌或上传事项内容。本版本未引入 Sparkle、自动替换、自动重启或新的签名方案。旧版没有更新检查功能，需要先手动安装本版。

用户存储、令牌服务标识与同步协议保持原样，不重置离线记录。服务端同时提供 0.4.0 镜像，但本轮没有新增服务端业务或协议变更；自托管服务端单独按部署指南升级，不由 Mac 更新提醒自动操作。

此构建仍为免费临时签名，**未通过 Apple 公证**。核对本仓库来源与 SHA256SUMS，首次下载若被系统阻止，可在系统设置 → 隐私与安全性中查看“仍要打开”；保留系统安全保护。

源码、候选构建与正式下载分别记录于[验证记录](https://github.com/takboo/nianbox/blob/main/docs/verification.md)。Homebrew 文件操作通过不等于 Gatekeeper 首次下载启动或实际跨版本数据库运行验收；物理 Intel、多屏、VoiceOver、真实人类操作和真实手机／服务器部署仍需对应环境验证。
