# 念匣 0.3.0

这次更新让“记下了”和“同步好了”各有清楚的回应，也修好了快速记录与离线重试中的几处一致性问题。

- 菜单栏换上与 App 一致的抽屉和纸张图形，由真实录入、本地保存与同步状态驱动。连接失败、保存失败和删除冲突使用不同形状；空轮询保持安静，支持系统“减少动态效果”。
- Tasks 与 Backlog 各自保留未提交草稿，切换回来可继续；草稿仍仅在当前 App 会话内保留，退出前请保存。
- 修复写入已提交但响应丢失、随后 Hermes 又修改同一事项时，Mac 可能保留旧内容却显示“已同步”的问题。
- 服务端修复同一秒内截止时间过滤漏项，以及 MCP 等待 SQLite 写锁阻塞共享事件循环的问题；补齐分页整数上界和旧备份历史分叉检测。
- 中文 README 成为默认产品入口，提供英文版本；使用、开发、部署与验收分开维护，历史快照归档并从普通搜索屏蔽。

## 安装与升级

下载 `NianBox-0.3.0-universal.dmg`，打开后拖入 Applications，退出旧 App 后打开新版。支持 macOS 14+、Apple Silicon 与 Intel。

升级前备份数据；服务端使用同版本镜像。历史分叉保护需要客户端与服务端均升级，不能回溯检查第一次升级前的游标区间。现有存储不重置，令牌不变。截止时间目前仍不触发提醒。

此构建使用临时签名，**未通过 Apple 公证**。核对下载来源与 SHA256SUMS，首次打开若被拦截，在系统设置 → 隐私与安全性中查看“仍要打开”；保留系统安全保护。

自动测试与隔离 VM 的范围见 [验证记录](https://github.com/takboo/nianbox/blob/v0.3.0/docs/verification.md)。物理多屏、Intel 硬件、VoiceOver、真实手机 Hermes 与目标常开部署不在本次验收范围内。
