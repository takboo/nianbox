NianBox 的首个公开 macOS 安装包，支持 Apple Silicon 与 Intel Mac，最低 macOS 14。

- 新的 3D「念头抽屉」应用图标与菜单栏图标。
- 设置中录制全局快速记录快捷键；支持停用、恢复默认与冲突提示，退出重开后保留。
- 修正设置中的 GitHub 链接，打开本项目仓库。
- DMG 提供双语拖入 Applications 引导、安装说明与 SHA-256 校验。
- 同一版本发布 SQLite REST/MCP 服务端镜像；`stable` 在检查完成后指向此版本。
- 保留离线捕获、同步队列、完成历史和永久删除记录，不迁移或重置用户数据。

下载 `NianBox-0.2.0-universal.dmg`，打开后将 NianBox 拖入 Applications，再从应用程序启动。

此个人开源版本使用临时签名，**未通过 Apple 公证**。首次下载打开可能被 Gatekeeper 拦截；请核对本仓库来源与校验值，并在系统设置 → 隐私与安全性中自行查看“仍要打开”。无需关闭 Gatekeeper 或 SIP。没有引入付费 Apple Developer Program 依赖。

VM 与自动检查不代替物理多屏、真实手机 Hermes、常开服务器 HTTPS 部署及用户体验验收。
